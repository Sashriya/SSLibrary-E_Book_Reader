# 📚 SS Tamil Novels Library

A full-stack web application for Tamil novel enthusiasts to read, write, and share stories. Built with the MERN stack (MongoDB, Express.js, React, Node.js).

## ✨ Features

### 👤 User Features
- 🔐 User authentication (Register/Login with JWT)
- 👥 Follow/Unfollow users with request system
- 💬 Like and comment on stories
- 🔔 Real-time notifications
- 📖 Reading list management (Reading, Completed, Favorites)
- 🖼️ Profile customization (Profile picture, Cover image, Bio)
- 🔍 Search users and stories
- 📱 Fully responsive design

### ✍️ Author Features
- 📝 Write and publish stories
- 🖌️ Rich text editor for story content
- 🎨 Story cover image upload with cropping
- 📊 View story statistics (views, likes, comments)
- ✏️ Edit and manage your stories

### 👑 Admin Features
- 📊 Admin dashboard
- 📚 Manage all stories
- 👥 User management
- 🗑️ Delete inappropriate content

### 🎨 Advanced Features
- 📧 Email notifications (Password reset)
- 🔍 SEO friendly
- 📱 Mobile responsive design

## 🛠️ Tech Stack

### Frontend
- **React 19** - UI framework
- **React Router DOM 7** - Routing
- **Tailwind CSS** - Styling
- **Lucide React** - Icons
- **Axios** - HTTP client
- **React Easy Crop** - Image cropping

### Backend
- **Node.js** - Runtime environment
- **Express.js** - Web framework
- **MongoDB** - Database
- **Mongoose** - ODM
- **JWT** - Authentication
- **bcryptjs** - Password hashing
- **Multer** - File upload
- **Sharp** - Image optimization

### DevOps
- **Nodemon** - Development server
- **dotenv** - Environment variables
- **CORS** - Cross-origin resource sharing
- **Helmet** - Security headers
- **Express Rate Limit** - Rate limiting

## 📋 Prerequisites

- Node.js (v18 or higher)
- MongoDB (v6 or higher)
- npm or yarn package manager
- Gmail account (for email notifications)
